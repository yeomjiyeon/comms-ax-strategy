// ╔══════════════════════════════════════════════════════════╗ // ║ Comms AX Dashboard - Google Apps Script ║ // ║ 기존 스크립트의 doGet 함수를 아래 코드로 교체하세요 ║ // ╚══════════════════════════════════════════════════════════╝ // ★ 스프레드시트 ID - 기존 것 사용 const SPREADSHEET_ID = '여기에_스프레드시트_ID_입력'; // 기존 스프레드시트 ID function doGet(e) { const action = (e.parameter.action || '').trim(); try { if (action === 'saveAll') { return handleSaveAll(e); } else if (action === 'loadAll') { return handleLoadAll(); } else { // 기존 액션들 (호환성 유지) return handleLegacy(e, action); } } catch (err) { return jsonResponse({ success: false, error: err.message }); } } // ══ 전체 상태 저장 ══ function handleSaveAll(e) { const data = e.parameter.data; if (!data) return jsonResponse({ success: false, error: 'No data' }); const ss = SpreadsheetApp.openById(SPREADSHEET_ID); // "dashboard_state" 시트가 없으면 생성 let sheet = ss.getSheetByName('dashboard_state'); if (!sheet) { sheet = ss.insertSheet('dashboard_state'); } // A1에 JSON 전체 저장, A2에 타임스탬프 sheet.getRange('A1').setValue(data); sheet.getRange('A2').setValue(new Date().toISOString()); return jsonResponse({ success: true }); } // ══ 전체 상태 로드 ══ function handleLoadAll() { const ss = SpreadsheetApp.openById(SPREADSHEET_ID); const sheet = ss.getSheetByName('dashboard_state'); if (!sheet) { return jsonResponse({ success: true, state: null }); } const raw = sheet.getRange('A1').getValue(); if (!raw) { return jsonResponse({ success: true, state: null }); } try { const state = JSON.parse(raw); return jsonResponse({ success: true, state: state }); } catch (err) { return jsonResponse({ success: false, error: 'JSON 파싱 오류: ' + err.message }); } } // ══ 기존 액션 호환 (필요시) ══ function handleLegacy(e, action) { // 기존 tasks 로드 (action 없이 호출된 경우) if (!action) { return handleLoadAll(); } return jsonResponse({ success: false, error: 'Unknown action: ' + action }); } // ══ JSON 응답 헬퍼 ══ function jsonResponse(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
